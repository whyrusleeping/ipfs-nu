## Description
Specify/deploy project relay/lookup/DNS service model: operators, domain control, funding, regional capacity, reservations and full-service admission, abuse controls/quotas, failover, monitoring and service limits. Model idle nodes/keepalives and relayed bulk bytes. Support self/community deployments while preserving account-free content-command UX; identity-based admission is not preselected.

Acceptance: documented cost/capacity and admission decision; disposable development service first, operated endpoint/deployment runbooks and failure/quota tests before default-service recommendation; no hidden manual admission inside zero-config claim; no release dependence for private/isolated archives. Operator/budget choices may need human confirmation before production spending.
